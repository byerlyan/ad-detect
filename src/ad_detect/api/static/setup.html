AD Ad Detect Connecting…

Local setup

Make the signal trustworthy.

Nine short checks. Nothing controls playback until capture, recovery, and consent are proven.

    Private by default Probes and pairing stay on this Mac. Credentials never enter browser storage.

    01 / Orientation

    Detect commercials without guessing through a broken signal.

    Ad Detect processes capture locally and classifies every interval as program, commercial, or unknown. Black frames, missing audio, stale data, and protected content become unknown—never positive ad evidence.

    Detection-only

    Observe and label. Never change volume.

    Shadow

    Record hypothetical actions without controlling playback.

    Automatic

    Locked until shadow and restoration safety are verified.

    02–03 / Capture

    Choose one synchronized video and audio path.

    Discovery comes from FFmpeg’s AVFoundation view. Select exact devices; ambiguous names are rejected rather than guessed.

    
        
    

        
    
          
    03 / Audio
    
          
    Complete the synchronized A/V probe.
    
          
    The same bounded probe must negotiate both streams. Return to the capture selection if audio is unavailable or timestamps cannot be trusted.
    
          
          
    
        
    

        
    
          
    04 / Intervention
    
          
    Pair an Apple TV—or keep detection independent.
    
          
    Pairing credentials are written only by the backend with user-only permissions. Skip this step for detection-only or shadow operation.
    
          
    
            
            
          
    
          
    
          
    
            
            
          
    
        
    

        
    
          
    05 / Operating mode
    
          
    Start conservatively.
    
          
    
            
            
            
          
    
          
        
    

        
    
          
    06 / Optional calibration
    
          
    Visual calibration needs real preview evidence.
    
          
    The software contract is ready, but this build does not fabricate crop or black-frame calibration from a static browser preview. Skip with a recorded reason and revisit after the capture preview job is implemented.
    
          
        
    

        
    
          
    07 / Readiness
    
          
    Check what is actually available.
    
          
    Readiness verifies selected capture devices and any configured registry model. Optional detectors may remain disabled; missing requirements stay explicit.
    
          
          
    
        
    

        
    
          
    08 / Shadow validation
    
          
    Observe before acting.
    
          
    A bounded real-capture shadow job must verify queue health, unknown reasons, hypothetical actions, lease behavior, and restoration. That evidence is not yet produced by the browser service, so this gate remains locked.
    
          
    ⌁
    Server verification required
    Use the existing capture-shadow workflow for engineering validation; it does not automatically satisfy this setup gate.
    
        
    

        
    
          
    09 / Explicit consent
    
          
    Automatic mute is not available yet.
    
          
    This control appears only after a server-verified shadow run, safe absolute-volume capability, and restoration test. Setup progress alone can never enable it.
